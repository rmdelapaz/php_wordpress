📚 PHP and WordPress Development

Build real WordPress sites the way professionals do. Over nine modules you create the Pages & Co. bookstore website on WordPress 7.1 and PHP 8.5: a custom block theme, a plugin with books, genres and events, your own blocks, REST endpoints, tests, and a deployment you can show an employer.

📚 About This Course

WordPress runs a large share of the web, and most of it is customized by developers: themes, plugins, blocks and integrations. This course teaches that work. It assumes you already know PHP and SQL, so it starts where WordPress starts: how a request becomes a page, how content is stored, and the hooks system every line of WordPress code plugs into.

Every lesson has worked examples whose output was produced on a real WordPress 7.1 site, a hands-on project step for Pages & Co., exercises with solutions, a quiz, and a learning journal prompt. You work in a local Docker environment you set up in Lesson 1.2, with WP-CLI from the first day.

What You'll Learn

  • How WordPress works inside: the request lifecycle, the content model, the database tables, and load order
  • The hooks system (actions and filters), the core skill behind every theme and plugin
  • Block themes: theme.json, templates and template parts in block markup, patterns, style variations, and child themes
  • Classic and hybrid themes: the Loop, template tags, WP_Query, and functions.php
  • Plugins: structure and lifecycle, custom post types, taxonomies and meta, the Settings API, shortcodes, and custom tables
  • Security the WordPress way: validation, sanitizing, escaping, nonces, capabilities, and $wpdb->prepare()
  • Block development with Node 24 and @wordpress/scripts: static and dynamic blocks, block bindings, and the Interactivity API
  • The REST API: using it, adding your own endpoints, calling external APIs, transients, and WP-Cron
  • Professional workflow: debugging, PHPUnit and coding standards, performance, internationalization, accessibility, and deployment

Who This Course Is For

  • Developers who finished PHP Foundations and MySQL Foundations (or know the same material) and want to build with WordPress
  • Front-end developers who need to build or maintain WordPress themes and blocks
  • Freelancers and agency developers who customize client sites

Learning Path

This course is the third in a three-course sequence:

  1. MySQL Foundations: database fundamentals and SQL
  2. PHP Foundations: the PHP language, PDO, and security
  3. PHP and WordPress Development (this course): building WordPress themes, plugins and blocks

✅ Prerequisites

💡 Take these first (or know the same material)

  • PHP Foundations: functions, arrays, forms, sessions, classes, namespaces and Composer, PDO, and the security basics. This course does not re-teach PHP; Lesson 1.3 is a short refresher on how WordPress uses it.
  • MySQL Foundations: tables, keys, SELECT with JOINs, and indexes. Lesson 2.2 reads the WordPress tables with SQL.

You should also be comfortable with HTML and CSS, basic JavaScript (for the block lessons in Module 6), and the command line.

Required Software

  • Docker (Docker Desktop on Windows and macOS, Docker Engine on Linux): Lesson 1.2 builds the course environment with Docker Compose: WordPress 7.1 on PHP 8.5, MySQL 9.7, WP-CLI, and Mailpit
  • Node.js 24 for block development (Module 6)
  • A code editor: VS Code recommended
  • Optional: @wordpress/env (wp-env) and WordPress Playground, which Lesson 1.2 also shows
