🧩 PHP and WordPress Development: Course Syllabus

An instructor-led course in 18 three-hour sessions, in two parts. Set up a professional WordPress 7.1 development site, learn how WordPress works inside, build a custom block theme, then a plugin with custom post types, blocks, REST endpoints, tests and a real deployment: the Pages & Co. bookstore website, launched. Part 1, Themes (8 sessions), also runs on its own.

📚 Course Description

WordPress runs a large share of the web, and most of the paid work around it is development: themes, plugins, blocks, integrations and the upkeep of real client sites. This course teaches it the way professionals work in 2026: on a local Docker site with WP-CLI, debugging and a mail catcher, with WordPress's own conventions for PHP, hooks, security, internationalization and deployment.

Every command and every listing in the course was run on WordPress 7.1.3 with PHP 8.5 and MySQL 9.7 and shows its real output, with notes wherever PHP 8.4, MariaDB or other hosts differ. One project runs through every lesson: the website of Pages & Co., the bookstore of PHP Foundations and MySQL Foundations, from an empty block theme to a tested, deployed site.

🎯 By the end you will be able to

  • Run a reproducible WordPress 7.1 development site in Docker, control it with WP-CLI, and read every error in debug.log
  • Write PHP the WordPress way: coding standards, escaping, sanitizing and translation functions, callbacks and hooks
  • Explain WordPress's request lifecycle, file structure and database tables, and extend it with actions and filters
  • Build a custom block theme with theme.json, templates, patterns and style variations, a child theme, and classic templates with the Loop and WP_Query
  • Build a structured plugin with custom post types, taxonomies, meta, settings, custom tables and shortcodes, secured with nonces, capabilities and prepared SQL
  • Develop static, dynamic and interactive blocks with @wordpress/scripts, block bindings and the Interactivity API
  • Use and extend the REST API, call external APIs with caching and scheduled tasks, test, profile, translate and make a site accessible
  • Package, deploy and maintain a WordPress site, and launch a complete project of your own

Part 1 only: Sessions 1 to 8 (24 class hours, 13 lessons) run as a complete short course: from a local development site to a custom block theme, a child theme and classic templates, ending with the Part 1 project and assessment. Part 2, Plugins to Launch (Sessions 9 to 18), can follow later, or run on its own for learners who already have the Part 1 skills.

✅ Prerequisites

  • PHP Foundations and MySQL Foundations (rays-php.netlify.app, rays-mysql.netlify.app) or equivalent experience: functions and arrays, forms with validation and escaping, classes and namespaces, Composer, SQL SELECT, INSERT and JOIN.
  • A Windows 10/11 (with WSL 2), macOS or 64-bit Linux laptop that runs Docker, with 8 GB of memory or more and a few gigabytes of free disk space, on which you may install software.
  • The course site is set up at home before Session 1, following Lesson 1.2: Docker, the pagesco-dev project, WP-CLI and Mailpit. Module 6 adds Node.js 24 (or its Docker image).
  • Starting with Part 2 only: Part 1 or equivalent WordPress experience (hooks, a block theme with theme.json, the Loop and WP_Query, functions.php).

💡 Format

18 sessions × 3 hours = 54 class hours, one or two lessons per session (Session 8 teaches no new lesson: it is the Part 1 project studio and assessment; Sessions 7 and 17 teach one lesson each and give the rest of the time to project work: the Part 1 project, then the final project), in two parts: Part 1, Themes (Sessions 1 to 8) and Part 2, Plugins to Launch (Sessions 9 to 18). Every lesson on the course site is written for a solo learner and takes about 100 to 150 minutes, so two lessons do not fit whole in one room session. The room protects what is hardest alone: the mental model, a live demo you type along with, a guided lab with help on hand, and starting each lesson project. At home you finish the projects and do each lesson's exercises, quiz and journal entry on the free course site: about two to three hours between sessions.

Each session runs 0:00 to 3:00: a warm-up on last session, the first lesson, a 10-minute break, the second lesson, and a wrap-up with an exit ticket and the next bring list. Session 7 teaches one lesson and starts the Part 1 project; Session 8 is a studio for the Part 1 project and the Part 1 assessment; Sessions 17 and 18 give most of their time to the final-project studio.

🏁 Checkpoints, Assessment and Project

  • Self-checks and exit tickets in every session are practice, not grades: they tell you and your instructor what to revisit.
  • Checkpoint 1 (Session 4) and Checkpoint 2 (Session 13), 30 minutes each: short individual tasks on the modules just finished, scored with a short rubric.
  • Part 1 project and assessment (Sessions 7 and 8): a small theme for a client, built in the studio, and an individual assessment on Modules 1 to 4, scored with rubrics. When Part 1 runs on its own, they are the course's final assessment.
  • Final project (Sessions 16 to 18). From a short brief (Reserve & Pick Up: customers reserve Pages & Co. books online and pick them up in the store), you plan and build it across the theme, the plugin, a block and a REST endpoint, secure and test it, deploy it and present the result. A well-reasoned modest project scores as well as an elaborate one.

🧰 Required Software and Data

  • Docker: Docker Desktop (Windows with WSL 2, macOS) or Docker Engine with the Compose plugin (Linux); the course project runs WordPress 7.1 on PHP 8.5, MySQL 9.7, WP-CLI and Mailpit in containers
  • A code editor: VS Code (free) with a PHP extension such as PHP Intelephense; any code editor will do
  • Node.js 24 LTS (Part 2): for block development from Module 6, or the official node:24 Docker image
  • Composer (Part 2): through the official composer:2 Docker image; nothing to install
  • No accounts or paid tools: everything runs on an ordinary laptop; WordPress Playground and wp-env are shown as free alternatives, and deployment options are compared in Lesson 8.4

The course site is set up once, at home, before Session 1, following Lesson 1.2 (Docker and the pagesco-dev project). Your instructor sends a setup guide and an environment check a week ahead; Session 1 has an install clinic for anything that went wrong. Node.js 24 and the Composer image are needed from Part 2; Session 9 checks them.
