Every name here is the one the course uses: the pagesco theme, the pagesco-books plugin with the namespace PagesCo\Books, the prefix pagesco_. The wp shortcut, in ~/.bashrc or ~/.zshrc (bash/zsh) or your PowerShell profile:

alias wp='docker compose --progress quiet run --rm wpcli wp'
function wp { docker compose --progress quiet run --rm wpcli wp @args }

Inside the container the current folder is always the WordPress root, /var/www/html, which is your wordpress/ folder: wp eval-file check.php runs wordpress/check.php. Install and permalinks, as Lesson 1.2 runs them:

docker compose run --rm wpcli wp core install --url=http://localhost:8080 --title="Pages & Co." --admin_user=admin --admin_password=password --admin_email=wordpress@example.com --skip-email
docker compose run --rm wpcli wp rewrite structure '/%postname%/'

printf 'PAGESCO_UID=%s\nPAGESCO_GID=%s\n' "$(id -u)" "$(id -g)" > .env
cp config/compose.linux.yaml compose.override.yaml
mkdir wordpress

🪝 Hooks

Taught in Lesson 2.3. An action runs code at a moment; a filter changes a value and must return it.

add_action( 'wp_body_open', 'pagesco_render_store_notice' );            // priority 10, 1 argument
add_filter( 'pagesco_store_notice', 'pagesco_notice_late_opening', 20 );  // runs after priority 10
add_filter( 'the_title', 'pagesco_title_with_id', 10, 2 );               // ask for 2 arguments

function pagesco_title_with_id( $title, $post_id ) {
	return $title;                                                     // a filter always returns
}

remove_action( 'wp_head', 'wp_generator' );                              // same hook, callback and priority
var_dump( has_filter( 'the_content', 'wpautop' ) );                       // the priority, or false

// Your own hooks (prefixed, documented):
$text = apply_filters( 'pagesco_store_notice', 'Free shipping on orders over $35.' );
do_action( 'pagesco_before_store_notice' );

🛡️ Escaping, Sanitizing, Nonces and Capabilities

Introduced in Lesson 1.3, made a habit in Lesson 5.3. Sanitize early (when data arrives), escape late (when you print it), and check a nonce and a capability before every change.

Output goes intoEscape with
text between tagsesc_html(), esc_html__(), esc_html_e()
an attribute valueesc_attr(), esc_attr__(), esc_attr_e()
href, src, a redirectesc_url() (drops javascript:); esc_url_raw() for storage and HTTP requests
HTML that may contain safe tags (post content)wp_kses_post()
JavaScriptwp_json_encode() with wp_add_inline_script(); esc_js() for small inline values
Input isSanitize or validate with
one line of textsanitize_text_field( wp_unslash( $_POST['x'] ) )
several linessanitize_textarea_field()
a whole number / an IDabsint()
a slug or keysanitize_key(), sanitize_title()
an email addresssanitize_email(); is_email() validates
one of a few valuesin_array( $value, $allowed, true )
a pricemax( 0, (float) $value )
a dateDateTime::createFromFormat( 'Y-m-d', $value ), then compare its format() with the input
 
// A form: the nonce field, then in the handler the nonce, the capability, the work.
wp_nonce_field( 'pagesco_books_save_details', 'pagesco_books_details_nonce' );

if ( ! isset( $_POST['pagesco_books_details_nonce'] )
	|| ! wp_verify_nonce( sanitize_key( wp_unslash( $_POST['pagesco_books_details_nonce'] ) ), 'pagesco_books_save_details' ) ) {
	return;
}
if ( ! current_user_can( 'edit_post', $post_id ) ) {   // a meta capability: this post, this user
	return;
}

// A link to admin-post.php, and its handler (Lesson 5.3's stock action):
$url = wp_nonce_url( add_query_arg( array( 'action' => 'pagesco_books_toggle_stock', 'book' => 30 ), admin_url( 'admin-post.php' ) ), 'pagesco_books_toggle_stock_30' );

add_action( 'admin_post_pagesco_books_toggle_stock', function () {
	$book_id = isset( $_GET['book'] ) ? absint( $_GET['book'] ) : 0;
	check_admin_referer( 'pagesco_books_toggle_stock_' . $book_id );   // 403 "The link you followed has expired."
	if ( ! current_user_can( 'edit_post', $book_id ) ) {
		wp_die( esc_html__( 'Sorry, you are not allowed to change this book.', 'pagesco-books' ), 403 );
	}
	// ... change it ...
	wp_safe_redirect( admin_url( 'edit.php?post_type=book' ) );
	exit;
} );

// SQL with a variable: always prepare(). %s string, %d integer, %f float, %i identifier (6.2+).
global $wpdb;
$count = $wpdb->get_var( $wpdb->prepare( 'SELECT COUNT(*) FROM %i WHERE location = %s', $wpdb->prefix . 'pagesco_events', $location ) );

defined( 'ABSPATH' ) || exit;   // first line of every PHP file that can run on its own (Lesson 5.1)

Remember: functions such as wp_insert_post() and update_post_meta() never check permissions, and a nonce proves a request is genuine, not that the user is allowed.

🔁 The Loop, Template Tags and WP_Query

Lesson 4.1 and Lesson 4.2.

<?php
while ( have_posts() ) {
	the_post();
	the_title( '<h2><a href="' . esc_url( get_permalink() ) . '">', '</a></h2>' );
	the_excerpt();
}
the_posts_pagination();

// A secondary Loop: its own WP_Query, then always wp_reset_postdata().
$pagesco_news = new WP_Query(
	array(
		'category_name'       => 'news',      // a slug; 'cat' takes IDs
		'posts_per_page'      => 3,
		'ignore_sticky_posts' => true,
		'no_found_rows'       => true,        // skip the count when you do not paginate
	)
);
while ( $pagesco_news->have_posts() ) {
	$pagesco_news->the_post();
	get_template_part( 'template-parts/content', null, array( 'show_date' => true ) );   // no .php
}
wp_reset_postdata();

// Changing the main query: pre_get_posts, with guards.
function pagesco_classic_adjust_main_query( $query ) {
	if ( is_admin() || ! $query->is_main_query() ) {
		return;
	}
	if ( $query->is_home() ) {
		$query->set( 'posts_per_page', 3 );
	}
}
add_action( 'pre_get_posts', 'pagesco_classic_adjust_main_query' );
ArgumentExample
type and status'post_type' => 'book', 'post_status' => 'publish'
how many, which page'posts_per_page' => 6, 'paged' => 2
terms'tax_query' => array( array( 'taxonomy' => 'genre', 'field' => 'slug', 'terms' => 'fantasy' ) )
meta'meta_key' => 'pagesco_price', 'orderby' => 'meta_value_num'; 'meta_query' => array( … )
people and dates'author_name' => 'devon', 'date_query' => array( array( 'year' => 2026, 'month' => 9 ) )
search and lists's' => 'club', 'post__in', 'post__not_in', 'post_name__in'

only IDs'fields' => 'ids' (then update_postmeta_cache( $ids ) before reading meta)

Results: $q->post_count (this page), $q->found_posts (all), $q->max_num_pages. get_posts() returns an array, defaults to 5 posts and needs no reset. Template tags come in pairs: the_title() prints, get_the_title() returns; only the_content() renders blocks and shortcodes.
