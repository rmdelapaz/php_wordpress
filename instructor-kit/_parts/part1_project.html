Part 1 Project: Scoring Guidance by Row

  • Start with the learner's run, not yours: unzip into a course site at the end of Lesson 4.3 as wp-content/themes/fernhill/, wp theme activate fernhill, run test_fernhill.php and the per-URL check (both below), click through the pages with tail -f wordpress/wp-content/debug.log open. Ten minutes per learner, then read the code.
  • Design system. Open theme.json next to the brief: five slugs in order, defaultPalette false, both widths. Grep templates and patterns for # hex values: hand-set colors in markup cap the row at 2 (the variation cannot change them). The Autumn file must reuse the SAME slugs (a variation that renames slugs changes nothing).
  • Templates and parts. The self-check confirms files and areas; you confirm landmarks on EVERY template (the per-URL check) and the 404 status. A part slug typo shows on one page only: exactly what the check is for.
  • Patterns. Count translatable strings: every visible string, the alt text with esc_attr_e(), the text domain fernhill (not pagesco, the most common copy-paste slip: the self-check catches it). A hard-coded http://localhost:8080/about/ caps the row at 2: it breaks on any other site.
  • functions.php and the main query. Read the pre_get_posts callback: all three guards, $query->is_home() (the method) and $query->set(). The self-check passes without the main-query guard (see the trap below): you score the code, not the check. The stylesheet's version must come from the theme (wp_get_theme()); a typed '1.0.0' is a 3 only if NOTES.md says why.
  • Quality. No message in debug.log for the whole click-through; prefixes on every function; wp post list --post_type=wp_template,wp_template_part,wp_global_styles --fields=ID,post_name shows no Fernhill copies (or NOTES.md explains one); NOTES.md has its three parts.
  • Revision: below Met, write the two rows to fix on the sheet; the learner resubmits once within a week. Own client: a learner may ask in Session 7 to theme another fictional client with the same requirement shapes (five role colors, two patterns, the main-query change); approve it in writing, and their NOTES.md then lists their exact texts so you can check them.

functions.php, the part learners find hardest
/**
 * Shows three news posts per page on the blog home (the front page of this site).
 *
 * @param WP_Query $query The query WordPress is about to run.
 */
function fernhill_adjust_main_query( $query ) {
	if ( is_admin() || ! $query->is_main_query() ) {
		return;
	}

	if ( $query->is_home() ) {
		$query->set( 'posts_per_page', 3 );
	}
}
add_action( 'pre_get_posts', 'fernhill_adjust_main_query' );
