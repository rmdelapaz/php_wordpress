8.3 · Translator-friendly

The string rules

  • Whole sentences: sprintf( __( 'Books in %s' ), $genre )
  • Numbered: %1$s of %2$s, with a translators comment
  • Counts: _n() · ambiguous words: _x()
  • Literals only; escape the translation

8.4

Deployment & Maintenance

Launch day as a routine.

8.4 · Mental model

Code up, content down, configuration stays

  • Code: Git, a release build, a deploy; never edited on the server
  • Content: the database moves once; then copies come down
  • Configuration: written per environment, never copied
SURPRISE A Site Editor change on the live site is content.
