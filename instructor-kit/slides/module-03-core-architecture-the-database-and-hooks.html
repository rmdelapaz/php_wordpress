2.2 · The tables

Twelve tables, five groups

  • Content: wp_posts, wp_postmeta
  • Taxonomies: wp_terms, wp_term_taxonomy, wp_term_relationships, wp_termmeta
  • Users: wp_users, wp_usermeta
  • Comments: wp_comments, wp_commentmeta
  • Settings and legacy: wp_options, wp_links
RULE Linked by ID columns. Zero foreign keys: integrity lives in PHP.

2.2 · A join

Who wrote each post?

SELECT p.ID, p.post_title, u.display_name AS author
FROM wp_posts AS p JOIN wp_users AS u ON u.ID = p.post_author
WHERE p.post_type = 'post' AND p.post_status = 'publish' ORDER BY p.ID;

2.2 · WP_Query

The SQL WordPress writes for you

wp eval-file query-news.php
SELECT SQL_CALC_FOUND_ROWS  wp_posts.ID
FROM wp_posts  LEFT JOIN wp_term_relationships ON (wp_posts.ID = wp_term_relationships.object_id)
WHERE 1=1  AND (
wp_term_relationships.term_taxonomy_id IN (2)
) AND ((wp_posts.post_type = 'post' AND (wp_posts.post_status = 'publish')))
GROUP BY wp_posts.ID
ORDER BY wp_posts.post_date DESC
LIMIT 0, 10

Found: 17, 16, 15
WHY One join, the defaults, pagination: the API knows the schema.

2.3

The Hooks System

Which hook, and is it an action or a filter?

2.3 · Mental model

A radio show with call-ins

  • Action: "we are at the weather, any callers?" The show goes on
  • Filter: "here is the headline, any corrections?" Pass it on
  • Each caller hands the headline to the next one
  • Hand back nothing, and the host reads out nothing
RULE Action = a moment, do something. Filter = a value, return it.
2.3 · Your first hook

Two lines do the work

<?php
/**
 * Plugin Name: Pages & Co. Hello Hooks
 * Description: Lesson 2.3 demo: prints a line at the bottom of every page.
 */

function pagesco_hello_footer() {
	echo '<p class="pagesco-hello">Hello from a hook!</p>';
}
add_action( 'wp_footer', 'pagesco_hello_footer' );
<p class="pagesco-hello">Hello from a hook!</p>
WHY A name as a string, no parentheses: what to call later.

2.3 · Accepted arguments

Ask for the second value

<?php
function pagesco_title_with_id( $title, $post_id ) {
	return "{$title} (#{$post_id})";
}
add_filter( 'the_title', 'pagesco_title_with_id', 10, 2 );

echo get_the_title( 1 ), "\n";
echo get_the_title( 2 ), "\n";
Hello world! (#1)
Sample Page (#2)
WHY 10, 2: default priority, two arguments.

2.3 · Mistake 3

A typo in the callback name

  • add_action( 'init', 'pagesco_register_thing' ); (no s)
  • add_action() stores the string; nothing checks it
  • init fires: TypeError, the whole site down, WP-CLI too
  • A must-use plugin cannot be paused: rm the file from the host
WATCH Copy the name from the definition; check with has_action().

WATCH Silent. var_dump() the return value.
