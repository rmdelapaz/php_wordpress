4.3 · Enqueue

Handle, src, deps, ver, args

  • wp_enqueue_style( 'pagesco-classic-style', ... )
  • src: get_parent_theme_file_uri( 'style.css' )
  • ver: wp_get_theme( get_template() )->get( 'Version' )
  • scripts: array( 'strategy' => 'defer', 'in_footer' => true )
RULE On wp_enqueue_scripts. Never a typed version.

4.3 · Menus

Locations, not links

  • The theme: register_nav_menus( array( 'primary' => ... ) )
  • The owner: builds the menu, assigns it
  • The template: wp_nav_menu() behind has_nav_menu( 'primary' )
  • current-menu-item and aria-current for free
WATCH No menu assigned, no guard: every page, Sample Page too.
4.3 · Widget areas

A slot the owner fills

  • register_sidebar() with a fixed id, on widgets_init
  • %1$s and %2$s in before_widget: the widget's id and classes
  • is_active_sidebar() + dynamic_sidebar() in footer.php
  • Since 5.8 widgets are blocks: wp widget add block footer
WATCH No id: sidebar-1, and the widgets move when areas change.
