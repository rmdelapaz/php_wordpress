4.1

The Loop & Template Tags

The list is done before the template runs.

4.1 · Mental model

The reading list at the till

  • The main query found the posts before any template ran
  • have_posts(): another book on the list?
  • the_post(): take the next one off the pile
  • Template tags: read out its title, author, date
  • Forget the_post() and you read the same title forever
4.1 · The request

URL, query, template, Loop

  1. The URL becomes query vars: category_name=news
  2. The main query runs; its result waits in $wp_query
  3. template-loader.php picks the template (Lesson 3.1)
  4. The template's Loop walks the result
RULE A classic template never asks which posts.

4.1 · Template tags

Printed or returned

  • the_title() prints · get_the_title() returns
  • the_permalink() · get_permalink() + esc_url()
  • the_title_attribute() in title=""
  • get_the_content() is raw; the_content() renders blocks
  • the_date() once per day; get_the_date() every time
RULE Printing is not escaping: escape what you print yourself.

/book-club-dune/ -> is_singular, is_single
