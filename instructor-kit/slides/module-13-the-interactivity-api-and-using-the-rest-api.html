6.4

The Interactivity API

The server renders it, a small store takes over.

6.4 · Mental model

The stage and the lighting desk

  • The server builds the stage: every book, every link, finished
  • Directives are cables from each light to a fader
  • The store is the desk: move one fader, every light follows
  • You touch the faders; the cables do the rest
RULE The server evaluates the directives too: right before any JavaScript.
6.4 · Design first

State, derived state, context

  • State: the one thing a click changes: genre
  • Derived: isVisible, isSelected, visibleCount
  • Context: what each element knows about itself: slug, genres
  • PHP closures for the server, getters for the browser: the same answers

The shop's service counter.

7.1 · Mental model

The service counter

  • The shop floor is HTML; the counter answers in JSON
  • Anyone may ask for public information
  • Changes: who are you (authentication), then may you (permission)
  • Every answer: JSON, a status, headers
WORDS base /wp-json/ · namespace wp/v2 · route · endpoint = route + method

7.1 · Who is asking?

Cookie, nonce, wrong nonce

WHY No nonce: anonymous. Wrong nonce: refused (CSRF).
7.1 · Application passwords

A program's own credentials

curl -s --user "maria:$PASS" -X POST -H 'Content-Type: application/json' -d '{"meta":{"pagesco_price":12.99}}' 'http://localhost:8080/wp-json/wp/v2/books/30?_fields=id,meta.pagesco_price'
{"id":30,"meta":{"pagesco_price":12.99}}
WHY Basic authentication: HTTPS or a local site, one password per program.
7.1 · When the answer is no

Read the status first

  • 400 the request is wrong: data.params says which argument
  • 401 who are you? (rest_not_logged_in, rest_cannot_edit)
  • 403 I know you, and no (Devon on Maria's book)
  • 404 no such route, or no such item
WATCH Same code, rest_cannot_edit: 401 anonymously, 403 for Devon.

7.1 · apiFetch

fetch() without the nonce

> await ( await fetch( '/wp-json/wp/v2/users/me?_fields=id,name' ) ).json()
{"code":"rest_not_logged_in","message":"You are not currently logged in.","data":{"status":401}}
> await wp.apiFetch( { path: '/wp/v2/users/me?_fields=id,name' } )
{"id":2,"name":"Maria Lopez"}

Network:  GET /wp-json/wp/v2/users/me?_fields=id,name                        no X-WP-Nonce header   401
          GET /wp-json/wp/v2/users/me?_fields=id%2Cname&_locale=user          X-WP-Nonce header      200
WATCH wp.apiFetch sends the nonce, the root URL and the locale.
