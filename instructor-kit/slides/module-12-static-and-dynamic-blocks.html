The saved HTML is the data.

6.2 · Mental model

A printed card with a sticky note

6.2 · The fix

A deprecated entry

  • The old attributes, the old supports, the old save
  • migrate( attributes ): old cards keep showBadge: false
  • Newest first; the first that reproduces the HTML wins
  • Console: Block successfully updated, nothing saved yet
RULE CSS and edit never need one. New HTML for existing content always does.
