7.2 · Who may

permission_callback

  • __return_true: public reads only, such as the catalog
  • Writes: current_user_can( ...capability... )
  • rest_authorization_required_code(): 401 for nobody, 403 for someone
  • Checking inside the callback is too late
RULE Bots find open write routes within days.

7.3 · WP-Cron

Three consequences

  • Times are earliest times: the next request after 3:00
  • No visitors, no jobs: system cron in Lesson 8.4
  • Jobs run without a user: no capability checks
  • Schedule once, on activation, guarded by wp_next_scheduled()
WATCH wp cron event run moves a recurring event: fire the hook instead.
