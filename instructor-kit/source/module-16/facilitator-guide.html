Questions and answers
  1. W1 (Lesson 8.1). On a live site, where do PHP's messages go, and why not to wp-content/debug.log? Answer: To a log outside the web root (or the server's log), display always off: wp-content/debug.log is a public download (200 for anyone).
  2. W2 (Lesson 8.1). Which command runs the plugin's tests, and in which site? Answer: npx @wordpress/env run cli --env-cwd=wp-content/plugins/pagesco-books vendor/bin/phpunit, in the plugin's own wp-env test site on port 8889, never in the site you develop on.
  3. W3 (Lesson 8.2). get_posts() with 'fields' => 'ids', then get_post_meta() for each ID: what is that called, and the fix? Answer: N+1 queries; update_postmeta_cache( $ids ) before the loop loads all the meta in one query.
  4. W4 (Lesson 8.2). What makes a cached result of EventsTable::find() unreachable after a new event is added? Answer: add() calls flush_cache(), which renews wp_cache_get_last_changed( 'pagesco_events' ), and that value is part of every key.
  5. W5 (Lesson 8.2). The theme's hero image got two fixes. Which, and what did each change? Answer: The Image block's aspectRatio (CLS 0.101 to 0.001: the space is reserved) and a preload with fetchpriority high in wp_preload_resources (LCP a little earlier).
Watch-outs
  • No tests run yet (wp-env did not start at home): fine for today; they must be green before Session 17, because Lesson 9.1's Milestone 7 adds five.
  • A learner still on 8.1's project: the 8.3 labs run on the 8.2 state; they finish 8.2's Steps 4 and 5 before 8.3's Step 5.

Internationalization, Accessibility & Distribution

60 min
Objectives (from the lesson page)
  • Generate a POT file with wp i18n make-pot, write translator-friendly strings, and produce .mo, .l10n.php and JavaScript .json translations with WP-CLI

Mental model to say

"A publisher who buys a novel does three things before every reader can have it. The manuscript is prepared for translators: nothing that only works in English. Translators produce the Spanish edition. And there are editions for readers who read differently: large print, an audiobook." On the board: i18n = your code, every string through a translation function with the text domain, in a form a translator can work with; l10n = translation files, from anyone, later; a11y = a quality of every page.

Then distribution in one sentence: "Pages & Co. Books is installed on one site, and it is still distributed: to staging, to the live site, to the next developer, as a ZIP with a version number. Building it to the directory's standard is the professional baseline."

Deployment & Maintenance

65 min
Objectives (from the lesson page)
  • Choose a hosting type for a WordPress project by what it needs, and explain how code, content and configuration move between development, staging and production

Objectives (from the lesson page)
  • Turn a client's brief into data, rules, routes, blocks and screens, and decide where each rule is enforced
  • Build a feature through every layer of the course: a custom table, settings, a service class with a custom hook, REST routes with real permission callbacks, form handlers, a staff screen, a dynamic and an interactive block, and a theme pattern with live data
