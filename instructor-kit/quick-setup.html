Get Ready in Under an Hour

Before the first session: install Docker, unpack the course project pagesco-dev, start it, install WordPress 7.1 on PHP 8.5, run the check. You need a laptop with 8 GB of memory, about 10 GB free, and a code editor (VS Code). The first start downloads about 3 GB: do it at home. Stuck? The full Setup Guide covers every problem, the offline images and the Part 2 setup (Node 24, Composer, the Part 2 starting site).

1 · Install Docker (pick one)

  • Windows 10/11: in PowerShell as administrator wsl --install, restart, create your Ubuntu user. Install Docker Desktop (WSL 2 backend), then Settings ▸ Resources ▸ WSL integration ▸ switch on Ubuntu. Use the Ubuntu app for every command and keep the project in ~, never under /mnt/c/ (many times slower).
  • macOS: install Docker Desktop for Mac (Apple silicon or Intel), start it once.
  • Linux: Docker Engine + the Compose plugin from docs.docker.com/engine/install, then sudo usermod -aG docker "$USER" and log out and in.

Check: docker compose version (with a space) prints version 2 or newer.

2 · Get the project

cd ~
curl -LO https://rays-php-wordpress.netlify.app/downloads/pagesco-dev.zip
unzip pagesco-dev.zip
cd pagesco-dev

No unzip on Ubuntu/WSL? sudo apt install unzip. Linux and WSL only, before the first start (so the files in wordpress/ are yours, not uid 33's):

printf 'PAGESCO_UID=%s\nPAGESCO_GID=%s\n' "$(id -u)" "$(id -g)" > .env
cp config/compose.linux.yaml compose.override.yaml
mkdir wordpress

3 · Start it and install WordPress

docker compose up -d
docker compose run --rm wpcli wp core install --url=http://localhost:8080 --title="Pages & Co." --admin_user=admin --admin_password=password --admin_email=wordpress@example.com --skip-email
docker compose run --rm wpcli wp rewrite structure '/%postname%/'

Open http://localhost:8080 (log in at /wp-admin/ as admin / password). Then the wp shortcut; add the same line to ~/.bashrc (macOS: ~/.zshrc):

alias wp='docker compose --progress quiet run --rm wpcli wp'

4 · Email and labs

mkdir -p wordpress/wp-content/mu-plugins
cp config/mailpit-smtp.php wordpress/wp-content/mu-plugins/

Mailpit shows the site's email at http://localhost:8025. Copy the labs/ folder from your instructor into pagesco-dev, next to compose.yaml (not inside wordpress/).

5 · Run the check

bash labs/module-01/l1_0-orientation/check_environment.sh
✅ Done when the last line says READY for PHP and WordPress Development

Send that line to your instructor. READY WITH NOTES is fine (read the CHECK lines: PHP 8.4, or a project on the Windows drive). NOT READY? Fix the FIX lines from the top (each names the step), run it again; still stuck: the full guide's problems table, or bring the output to Session 1's install clinic.

If something goes wrong

You see…Try this
port is already allocatedAnother container or server uses 8080 or 8025: docker ps, stop it.
Permission denied in wordpress/wp-contentLinux/WSL setup of step 2 missing: the Setup Guide's repair box.
no configuration file providedNot in the project folder: cd ~/pagesco-dev. Anything else: the Setup Guide, or the course's troubleshooting.html and common-errors.html pages (rays-php-wordpress.netlify.app).
